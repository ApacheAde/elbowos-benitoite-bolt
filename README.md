# Benitoite Bolt

Full-colour Python 3 neon bolt-chain arcade for ElbowOS.

Slide a charged amber orb along a copper rail. Fire a bolt through falling storm rings. Same-hue chains multiply the score. Violet drains leak charge.

A / D or arrows move. Space / W fires. R restarts.

This is original arcade code. It is not a Nintendo ROM and not an emulator.

## Play

```
pip install -r requirements.txt
python3 benitoite_bolt.py --play
```

## Record a 9:16 reel

```
python3 benitoite_bolt.py --record
```

Writes BENITOITE_BOLT_ElbowOS.mp4 (1080x1920, 15 seconds, 30fps, H.264, yuv420p).
